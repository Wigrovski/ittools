# ITTOOLS

Минималистичный статический веб-проект с набором локальных онлайн-инструментов для разработчиков.

## Стек и особенности
- **Astro** (`output: 'static'`) — чистая генерация статического HTML без Node.js в продакшене.
- **Локальные ресурсы** — шрифты `Inter` и `JetBrains Mono` подключены через `@fontsource` и собираются локально без внешних CDN.
- **Приватность** — 0 cookies, 0 аналитики, все инструменты работают полностью на стороне клиента.

## Разделы
- `/` — Главная страница
- `/tools/` — Генератор UUID v4, JSON Formatter & Validator, Конвертер Unix Timestamp
- `/about/` — Информация о проекте
- `/privacy/` — Политика приватности
- `/404.html` — Страница ошибки 404

## Команды
```bash
npm install
npm run dev
npm run build
```

Готовая статика собирается в директорию `dist/`.

## Размещение на Nginx
Скопируйте содержимое `dist/` на сервер (например, в `/var/www/ittools/dist`) и используйте конфигурацию из `nginx.conf.example`.
